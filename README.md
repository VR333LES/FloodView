# FloodView

A website to inform people about flooded areas during category 4 storms.

## Features

- Real-time maps (linked to flood reports)
- Elevation data for flood risk assessment
- Alerts
- Safety tips
- Data Sources: NYC 311 Street Flooding Reports, Elevation Data

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Real-time flood maps
- Storm alerts
- Safety tips
- Data from official sources

## Build

To build for production:

```bash
npm run build
npm start
```
